= Astra API（ACS）Kubernetes APIリソースエンドポイント
:allow-uri-read: 


Kubernetes API リソース API は、Kubernetes API リソースへの読み取り専用アクセスを提供し、特定のクラスタで Astra によってサポートされているリソースをフィルタリングします。
